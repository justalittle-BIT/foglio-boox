Foglio funziona nel browser e non carica i tuoi dati. I file vengono creati direttamente sul dispositivo. Vibe-coded with GPT-6 Luna.

Dal foglio a Note BOOX

1. Scegli il tipo di pagina, il formato e i colori.
2. Tocca Esporta PDF o Scarica PNG.
3. Salva il file in Storage/noteTemplate (puoi trasferirlo con BOOXDrop).
4. In Note, apri il menu Template → Custom → Add e seleziona il file.

Il formato “Schermo BOOX 3:4” segue le proporzioni del display in verticale; orientamento e dimensioni personalizzate sono regolabili.
